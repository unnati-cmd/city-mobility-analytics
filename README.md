# City Mobility Analytics Platform

## Overview
An end-to-end data engineering project that processes NYC taxi trip records to discover travel demand patterns, fare trends, and popular pickup and drop-off locations.

## Objectives
- Build a reliable batch data pipeline.
- Clean and validate raw trip records.
- Transform data using PySpark.
- Store curated data in Parquet format.
- Analyze mobility patterns using SQL.
- Build an interactive dashboard for exploring insights.

## Planned Technology Stack
- **Language:** Python
- **Orchestration:** Apache Airflow
- **Data Processing:** PySpark
- **Storage:** Parquet
- **Analytics:** Spark SQL
- **Dashboard:** Streamlit
- **Version Control:** Git and GitHub

## Data Source
NYC Taxi and Limousine Commission (TLC) Trip Record Data.

Official source: https://www.nyc.gov/site/tlc/about/tlc-trip-record-data.page

## Project Status
**In progress** — setting up the development environment and inspecting the source data.
